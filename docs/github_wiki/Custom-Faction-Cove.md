- Cove is basic-enabled from local HotA VCMI content only. The production-ready worktree has Cove import rows, unit bundles, portraits, hero portraits, town scene assets, city/dwelling billboard art, Cannon asset/audio payloads, extracted_battle lab sidecars, runtime registry rows, and generic release Core output enabled.
- Exact variant SID support exists in the manifest/runtime model, and the current import table maps Cove gameUnitSids to HotA lab/bundle payloads. Advanced mechanics are intentionally separate debt: Cannon behavior, Accurate Shot, Poison, Revenge, after-shot spells, and other source mechanics still need user-guided implementation.
- HoMM3 Complete LOD-only extraction is insufficient for Cove. Use vcmi/Mods/hota/mods/cove/Content plus vcmi/Mods/hota/mods/cannon/Content as the primary source lane for HotA Cove creatures, town, map objects, heroes, sounds, Accurate Shot, and Cannon.
- Cannon config, battle/projectile/map sprites, icons, and WAV files are packaged under reference_pack/cannon/homm3_cove/ by tools/deploy_homm3_cove_assets.py --deploy-cannon. This is an asset-only payload; Cannoneering behavior remains user-guided mechanics work.
- Cove uses exact variant SIDs where the source docs require them. The manifest still maps ToA alternates through _upg_alt slots, while Pirate/Corsair/Sea Dog uses that third slot for HotA's second pirate upgrade.
- Swamp is the target native terrain, but releaseScaffold.biome is Autumn until release terrain support is expanded. Do not write a new biome id or rely on fallback behavior.
- Cove donor reverse lookup must remain context-required because Human, Nature, and Dungeon donors are shared with other custom factions and native factions.
- Local HotA contains more Cove hero configs than the current 18-hero manifest contract. Final hero inclusion and class split must be decided before release promotion.
