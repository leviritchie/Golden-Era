## Known Debt / Warnings

- Necropolis is currently a manifest/registry scaffold with source plugin unit import rows, bundles, static portraits, preview manifests, lab sidecars, hero portraits, faction art, city billboard art, and dwelling billboard frames present. It is not a promoted release Core overlay and still needs town/build-tree presentation, UI exposure, and mechanics validation.
- The current manifest schema is suffix-based, so display names preserve Skeleton Warrior, Zombie, Wraith, Vampire Lord, Power Lich, Dread Knight, and Ghost Dragon while stable SIDs remain h3_<base>_upg until the schema supports explicit per-variant SIDs.
- The tier-4 Guard branch, Skeleton Sharpshooter, and Dracolich are documented ToA extras but are outside the current seven-line faction manifest contract.
- Necromancy, Skeleton Transformer, Cover of Darkness, undead immunity parity, Lich death cloud, Vampire Lord life drain, Wraith mana drain, Ghost Dragon aging, and chance-proc-to-focus conversions remain static-trace/mechanics debt.
- Bone/Ghost/Spectral Dragon currently uses Dungeon Black Dragon as the visual donor while release Core generation must preserve Undead legality/immunity data.
- Necropolis donor reverse lookup must remain context-required because Undead donor units and barracks can also appear as native game content.
