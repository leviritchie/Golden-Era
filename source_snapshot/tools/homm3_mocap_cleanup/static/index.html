This is a lab for automatic skinning given a bind. Shift or lengthen bones first, then change the rules and apply. Not allowed: rotate a bone into a new rest pose.

Mode
Skinning rules

These rules replace every vertex's weights from the current bind. Old paint is discarded. Straight-line is quick. Surface walk can take a minute — watch the bar. The walk stays on the mesh: a UV seam is the same surface, but empty space between two parts is not a path. “Ignore narrow contacts” still walks the mesh, but a short glue between two parts is not a valid path if a long way around still exists.

0%

Whole-skeleton shift

Same knob as the pipeline: one yaw / pitch / roll, one scale, one slide. The mesh stays; the bones move.

Seat: pick a bone, then click the mesh. The whole skeleton slides so that bone goes to the click. Rotation sliders stay.

Bone length

This scales the bind-pose offset to the parent. Clip files only key rotations, so the same swings play on the longer or shorter bone. Hips has no offset — lengthen a child.

Follow keeps each vertex's mass on the moved chain and slides that mass onto the new bone segments. It does not invent rest rotations.

Weight paint

The mesh itself is the heat map: blue = this bone owns none, red = it owns the vertex. Texture is hidden in this mode. Drag to paint. Hold Alt to orbit.
