## 1. Scope: what â€œthe histogram featureâ€ is

- The game exposes a **numeric combat forecast** (min/max total damage and related fields) through a static helper that returns a small **DTO** (in interop: `global::ejy` with integer fields like `cgau` / `cgav`, etc.).
- The mod **postfixes** that call, reads the DTO, and (when enabled in config) computes a **probability mass** over **kills** for the defender stack, then draws a small **IMGUI** bar chart near the cursor.
- **Attack/defense and other combat rules** are *not* reimplemented: the engineâ€™s min/max totals are taken as given. A separate note (`HOMM3_damage_rolls.md` in this folder) explains the *shape* of the roll model used to spread probability inside that band.
- **Luck / crit** are optionally mixed on top of the base total-damage PMF so the overlay stays closer to how resolution-time rolls can behave.

Nothing in this file is required to be shared with end users; it is for **developers** porting the feature to a new game version.

## 3. Build and references

- **Target:** `netstandard2.1` (typical for BepInEx IL2CPP plugins).
- **References:** BepInEx (core, Unity IL2CPP, Il2CppInterop), Harmony, and **generated** `Hex.dll` + required Unity/UnityEngine interop assemblies, as listed in `OfflineUnlockMod.csproj`. Paths are **version-specific**; they must point at the interop set produced for **the same** game binary you are modding.

```bash
dotnet build -c Release
```

The project can copy the built DLL into a target `BepInEx/plugins/OfflineUnlockMod/` folder (see `DeployPluginToGame` in `OfflineUnlockMod.csproj`). By default, `GameRoot` is the adjacent playtest install (`$(MSBuildThisFileDirectory)..\`). To compile against or deploy to the released Steam install, pass the released game root explicitly:

```bash
dotnet build -c Release "-p:GameRoot=V:\Games\Olden Era Playtest Tweak\Heroes of Might and Magic Olden Era"
```

The direct Steam path is also valid and is the path to use when you intentionally want to deploy into the live release install:

```bash
dotnet build -c Release "-p:GameRoot=V:\SteamLibrary\steamapps\common\Heroes of Might and Magic Olden Era - Golden Era"
```

Do not treat `-p:UseLiveInteropOnly=true` as the official compile gate; it forces every interop assembly from the deobfuscated install and currently breaks Unity API surfaces such as `Vector3.one`. Type-name resolver for deobfuscated Hex owners lives in `tools/resolve_obfuscated_interop_types/`.

If the game is running and the file is locked, use `-p:DeployPluginToGame=false`. The **public zip** scripts (`package_release.ps1` / `package_release.sh`) build with that flag so packaging does not need the game closed. The project derives `GameRootDir` and `BepInExRootDir` internally; do not reassign command-line `GameRoot` inside MSBuild because global properties are immutable.
