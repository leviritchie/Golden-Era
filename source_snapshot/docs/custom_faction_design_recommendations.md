# Custom Faction Design Recommendations

Generated: 2026-05-25

Scope: every live city-hire custom HoMM3/HotA unit variant, generated custom hero, and live custom city building row in the Golden Era `Core.zip`, cross-checked against the three vanilla design philosophy docs, custom manifests, faction plan docs, and the May 22 custom building debt audit.

This is a design recommendation document, not an implementation patch. Future changes should update generator-owned data or traced runtime hooks, then validate the packed archive and live plugin state. Do not hand-edit `Core.zip` to satisfy a recommendation.

## Cross-Cutting Findings

- Units: keep source roles when they already create distinct choices; change missing live rows, implementation mismatches, duplicate presentation, and alternate upgrades that are only stat/name variants.
- Heroes: generated specializations are not source proof when `hero_overrides` has empty specialization payloads; replace them with source-confirmed HoMM3/HotA specialties.
- Buildings: the May 22 building audit made many native-supported substitutions honest. Keep those until exact source behavior is traced, but do not describe unsupported systems as working.
- Runtime/design rule: no broad donor fallbacks. Missing mechanics, icons, buildings, or source identities should fail validation or remain explicit debt.
