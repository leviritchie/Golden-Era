Status: source-validated static design audit, runtime-unvalidated.

Static extraction date: 2026-06-25.

Primary comparison target: `docs/olden_era_balance_bible_20260625.md`.

Primary custom data source: `artifacts/core_overlay_work/Core.zip`, summarized through `artifacts/balance_audit_20260625/custom_vs_vanilla_unit_snapshot.json`, `custom_rows_named.csv`, and the scratch recommendation context `unit_recommendation_context.json`.

Faction identity source: current generated hero-skill and subskill text from `artifacts/core_overlay_work/Core.zip`, generated by `tools/release_port/apply_release_core_overlay.py`.

## Method

The unit recommendations below compare each generated `h3_` custom unit row against the vanilla Olden Era tier philosophy:

- Tier 1: identity seed with one narrow hook.
- Tier 2: first real tactical choice.
- Tier 3: first local board rule.
- Tier 4: midgame pivot or engine.
- Tier 5: specialist power piece.
- Tier 6: late-game anchor.
- Tier 7: faction thesis and capstone payoff.

Each faction was reviewed against its current custom hero skill and subskills. The recommendation field is the concrete tuning or design action. The implementation target field is the parseable unit-identity instruction for a later implementation pass: it names the intended visible data surface, such as passive card, active ability, aura/global passive, attack pattern, AI tag, or no new mechanic. Identity mechanics should prefer differences of kind over differences of degree. Use stat, cost, and `squadValue` changes to balance the row, but use visible rules, targeting patterns, triggers, or role pivots to define the row's custom identity.

Priority terms:

- Fix: clear cost, `squadValue`, sidegrade, or tier-philosophy mismatch.
- Add implementation target: row can work numerically, but needs a visible rule, targeting pattern, trigger, aura, or role pivot to match the tier or faction.
- No material change: current row is acceptable for this tier; implementation target should usually preserve the current visible role or explicitly say no new mechanic.

Native-effect plausibility rule for implementation targets:

- Every implementation target below should be implemented by reusing an existing native or already-generated effect family, not by inventing a new runtime system.
- Named hook families used in this report include current unit cards and generated rows such as Double Shot, Double Strike, Swift Strike, Dragonbreath Strike, Area Strike, Sharpshooter, Piercing Shot/Fine Bolts, no-counter melee, Flying, Regeneration, Blind/Blinding Strike, Blessing, Misfortune, Curse/Dread Curse, Vulnerability, Disrupting Ray, Rotting Ray, Shambling Grasp, Zombie Clutch, Psychic Scream, Mana Channel, Vampirism, Animate Dead, Rewind Life, Reality Distortion, Repair, Web, Silence, Command Reposition, Command Switch Places, Command Fear, Refract and Reflect, Judgement, Vengeance, Glaivier Execute, Hypnotic Strike/Berserk, and Skeleton Transformer.
- Generated faction-skill and custom-law hook families are also acceptable when named explicitly: Shield Wall, Coordinated Volley, Avenger Mark, Withering Mark, Gating, Shielded Arrival, Rapid Gate, Efficient Gate, Warcries, Swamp Tactics, Thick Hides, Stagnant Air, Poisoned Mire, Bog Ambush, temporary-stack summon schema from Gating/Summon Elementals, Summon Elementals Focus/Spell Power scaling, and Bottomless Knowledge/Focused Study.
- If a later implementation agent cannot map a target to one of these existing hook families or another already-present native spell, unit, law, or ability schema, that target should be treated as blocked until a validator-backed native-effect contract is added.

## Castle - Elite Strategem

Identity lens: Castle is disciplined deployment and army coordination. Elite Strategem uses neutral-enemy formation choices, Forward Scouts, Signal Drills, Shield Wall, Rapid Redeployment, Valley Advantage, and Coordinated Volley. Castle unit identities should therefore be visible, formation-forward, and reliable rather than hidden or donor-dependent.

### Tier 1 - Pikeman Line

- Pikeman: No material change. It is a clean Tier 1 body at `SV 80`, `60g`, and should remain a simple defensive identity seed. Implementation target: no new mechanic: preserve current melee_attack spear baseline.
- Halberdier: No material change. It is a fair reliability upgrade with better offense, speed, and a narrow active. Implementation target: active card: keep Halberd Hook as the single disciplined-reach action; reuse the current active row shape without adding control.
- Glaivier: Keep the defensive stat split, but ensure its active remains narrow and defensive. Same `SV/cost` as Halberdier is acceptable only because it gives up offense and speed. Implementation target: active/passive card: replace broad offense with a Shield Wall-style basic-attack damage reduction passive using the existing Castle Shield Wall law modifier family.

### Tier 2 - Archer Line

- Archer: Fix by raising damage from `2-3` to `2-4`. Tier 2 should teach Castle ranged pressure before upgrades. Implementation target: no new mechanic: preserve ranged_attack baseline; implement only the damage correction.
- Marksman: No material stat change. Double Shot with low per-shot damage gives a readable standard upgrade. Implementation target: passive card: preserve Double Shot as the standard-upgrade rule; reuse the existing Double Shot card/effect family.
- Crossbowman: Fix the sidegrade by reducing initiative/speed from `7/7` to `5/5` while keeping `3-5` damage, Sharpshooter, and Fine Bolts. It is currently a strict combat-stat upgrade over Marksman. Implementation target: attack/passive card: make Fine Bolts the slow armor-piercing branch by reusing the existing Piercing Shot/Fine Bolts ranged attack family, with lower speed than Marksman.

### Tier 3 - Griffin Line

- Griffin: Fix `squadValue` to `320`. `SV 351` is high for a thin flyer/retaliation package. Implementation target: no new mechanic: preserve Flying and Alert as the row package; set `SV 320`.
- Royal Griffin: Fix `SV` toward `325-350` and make retaliation reliability the visible budget center. `SV 448` reads like Tier 4 without Tier 4 rule density. Implementation target: passive card: make Alert II retaliation reliability the visible standard-upgrade rule using the existing Alert/retaliation card family.
- Battle Griffin: Fix `SV` similarly and keep it as the lower-defense double-strike branch. The sidegrade concept is valid, but current valuation is too high. Implementation target: attack pattern: make Double Strike the alternate's kind difference using the existing Double Strike family, with lower defense than Royal Griffin.

### Tier 4 - Swordsman Line

- Swordsman: Add the Shield Wall-style guard passive named in the implementation target. Tier 4 is the midgame pivot; `mechanicCount 3` is too thin. Implementation target: passive card: add a Shield Wall-style basic-attack damage reduction passive using the existing Castle Shield Wall law modifier family.
- Crusader: No raw stat increase. Keep Double Strike as the standard upgrade's center and make sure it is card-visible. Implementation target: passive card: preserve Double Strike as the sole main rule using the existing Double Strike family.
- Guardsman: Fix the sidegrade by setting damage to `6-9` and letting guard/cover carry the alternate role. Current HP/defense/damage can read like a direct durability winner over Crusader. Implementation target: passive card: make guard identity a Shield Wall-style basic-attack damage reduction passive, with lower damage than Crusader.

### Tier 5 - Monk Line

- Monk: Add identity by raising HP toward `40` and adding a visible ranged-support hook. Current `30 HP`, low rule density, and no support text read closer to Tier 4 than Tier 5. Implementation target: passive card: add a Coordinated Volley-style ranged damage support passive using the existing Castle Coordinated Volley subskill modifier family.
- Zealot: Add a visible Coordinated Volley-style ranged rule and enough durability to compete with Priest as the ranged-support upgrade rather than a strictly frailer shooter. Implementation target: passive card: use the Coordinated Volley modifier family as the standard upgrade's ranged-support rule; avoid raw damage inflation.
- Priest: Fix valuation by setting `SV` to `850` while keeping `550g`, better HP/defense, Sharpshooter, and Bless, but remove Duelist and avoid making Priest faster than Zealot. Implementation target: active card: keep Blessing as a limited support action using the existing Blessing/Bless-style effect family, with Sharpshooter but no Duelist and no extra ranged damage rule.

### Tier 6 - Cavalier Line

- Cavalier: Add anchor quality by raising attack/defense toward `17/17` while keeping charge as the visible identity. `15/15` is below Tier 6 anchor expectations. Implementation target: attack pattern: keep Jousting Charge as the anchor mechanic using the current charge attack family.
- Champion: Add anchor quality by targeting about `19/18` offense/defense, with speed as the standard upgrade's advantage. The upgrade jump is too thin for Tier 6. Implementation target: attack pattern: make Rapid Assault the standard branch by reusing the current charge/assault action family after stat correction.
- Justiciar: Keep lower speed, raise defense/control visibility, and make Command Fear explicit. It should be the defensive/control sidegrade, not just a slower Champion. Implementation target: active card: make Command Fear the alternate's role using the existing Command Fear action family, with lower speed than Champion.

### Tier 7 - Angel Line

- Angel: Add allied basic-attack protection and cap speed at `11`. `SV 5019` is fine, but `mechanicCount 4` is low for a capstone. Implementation target: passive card: add card-visible allied basic-attack damage reduction using the existing Castle Shield Wall law modifier family.
- Archangel: Fix by reducing speed into the Tier 7 band, roughly initiative `14-16` and speed `11`, and bring `SV` below the vanilla ceiling. Rewind Life should be the budget center, not `18/18` mobility. Implementation target: active card: make Rewind Life the budget center using the current Rewind Life active row; reduce mobility around that action.
- Seraph: Apply the same mobility and `SV` correction, then define it as the support/prayer branch. Same `SV/cost` as Archangel is acceptable only if the support tradeoff is clear. Implementation target: active/aura card: make Reality Distortion the support branch using the current Reality Distortion row, not extra speed.

## Rampart - Avenger

Identity lens: Rampart spends Focus to mark enemies so they take more damage. Subskills add retaliation reduction, anti-healing/max-HP pressure, longer marks, Forest Advantage, adjacent marks, and extra Avenger Focus. Rampart units should express hunters, forest control, resistance, and marked-target follow-through.

- Centaur: No material change. `SV 100`, `70g`, and `6/6` tempo are high but readable as a fast Tier 1 seed. Implementation target: no new mechanic: preserve current fast melee_attack scout role; no Avenger-specific effect.
- Centaur Captain: Fix by reducing initiative/speed from `8/8` to `6/6` and normalizing `SV` near `120`. It currently exceeds Tier 1 tempo. Implementation target: no new mechanic: preserve reliable melee upgrade after speed/SV normalization.
- Centaur Ranger: Fix urgently as a ranged sidegrade: correct to ranged AI, target `SV 110-120`, and keep speed no higher than `6`. `SV 1366` at `90g` is a severe valuation anomaly. Implementation target: AI tag plus attack card: set `ai=range_type` and ranged_attack behavior, then reuse Sharpshooter/ranged_attack style data as the low-speed ranged sidegrade.

### Tier 2 - Dwarf Line

- Dwarf: Add the guard passive named in the implementation target; keep the slow speed. HP and Shield Set fit, but Tier 2 needs a clearer tactical choice. Implementation target: passive card: add a Shield Wall-style basic-attack damage reduction passive using the existing damage-reduction modifier family.
- Battle Dwarf: Fix by normalizing `SV` to `190`; do not solve the mismatch by raising cost. The `SV` correction is cleaner. Implementation target: passive card: make Runic Guard the standard upgrade's visible guard rule using the current Runic Guard card/effect family.
- Dwarf Battlerager: Fix valuation by targeting `SV 170-180` and giving it a visible aggressive reprisal rule. `SV 87` at `150g` is below base value despite better combat stats. Implementation target: passive card: add an Avenger-mark payoff passive using the existing Avenger Mark damage-taken modifier family, with lower defense than Battle Dwarf.

### Tier 3 - Wood Elf Line

- Wood Elf: No material stat change. `SV 234`, `200g`, ranged role, and fragile HP fit Tier 3 baseline pressure. Implementation target: no new mechanic: preserve base ranged_attack pressure; do not apply Avenger marks from the unit row.
- Grand Elf: Cap `SV` at the Tier 3 ceiling. Double Shot at `SV 331` is slightly over band. Cost raise withdrawn 2026-10-01: it priced the base above its own upgrade, so upgrading paid the player gold; gold is pinned at the HoMM3 `225`. Implementation target: passive card: preserve Double Shot as the standard upgrade's rule using the existing Double Shot family.
- Elf Wardancer: Fix by normalizing `SV` to roughly `260-290` and pricing near Grand Elf. The ranged-to-melee trade is valid, but `SV 52` is impossible for fast double-strike melee. Implementation target: attack pattern: make melee Double Strike the alternate's kind difference using the existing Double Strike family; loss of range remains the drawback.

### Tier 4 - Pegasus Line

- Pegasus: Add the Misfortune anti-caster rule named in the implementation target. Tier 4 wants an engine. Cost raise withdrawn 2026-10-01: it priced the base above its own upgrade, so upgrading paid the player gold; gold is pinned at the HoMM3 `250`. Implementation target: passive/aura card: add Misfortune pressure using the current Misfortune card/effect family.
- Silver Pegasus: Fix speed by reducing to `8`, while keeping high initiative. `12/12` mobility is overloaded for Tier 4. Implementation target: active/passive card: make Rivulet Retreat plus Misfortune the reliable anti-caster branch using the current Rivulet Retreat and Misfortune rows; normalize speed.
- Gold Pegasus: Fix `SV` to about `500-550` and reduce speed to about `8`, keeping no-retaliation plus Misfortune as the alternate. `SV 178` at `350g` is a severe low-value anomaly. Implementation target: active/passive card: use Hourglass plus Misfortune/no-retaliation as the control branch using current Hourglass and no-retaliation families.

### Tier 5 - Dendroid Line

- Dendroid Guard: Add identity by raising offense toward `12` and making Binding prominent. Slow tank is right, but `mechanicCount 3` and offense 9 are too low for Tier 5 specialist power. Implementation target: passive card: foreground Binding as the zone-control passive using the existing Binding card/effect family.
- Dendroid Soldier: Add the stronger Binding rule named in the implementation target and raise offense to `12`. `SV 803` is plausible but the row is mostly stats. Implementation target: passive card: strengthen Binding reliability using the existing Binding family; do not add speed.
- Dendroid Shaman: Fix `SV` to `775` and frame the active as Rampart regrowth/support rather than generic resurrection. `SV 302` at `550g` with active and defense gains is a cost/value anomaly. ### Tier 6 - Unicorn Line

- Unicorn: Add visible aura/resistance and raise defense toward `18`. It is priced as a Tier 6 anchor but has only `15/14` offense/defense and low rule density. Implementation target: active/passive card: use Blinding Strike plus a Shield Wall-style protection aura as the anchor package, reusing current Blind and damage-reduction families.
- War Unicorn: Add anchor quality by raising defense toward `18` and making Blind plus aura the standard package. Implementation target: active/passive card: make Blinding Strike the standard control rule using the existing Blind/Blinding Strike family.
- Pristine Unicorn: Fix the sidegrade by lowering speed to `7` while keeping stronger defense and stronger control. It is nearly a direct upgrade over War Unicorn for only `+100g`. Implementation target: active/passive card: make Radiant Armor the slower control-tank branch using the current Radiant Armor row plus Blind family.

### Tier 7 - Dragon Line

- Green Dragon: Add capstone quality by raising offense/defense to `22/20`; keep Dragonbreath Strike and Magic Immunity as the visible package. Breath and immunity are good, but the row is thin. Implementation target: attack/passive card: preserve Dragonbreath Strike and Magic Immunity as the base capstone package using existing dragonbreath/immunity families.
- Gold Dragon: Fix by reducing speed to `11`, keeping high initiative, and bringing `SV` under the Tier 7 ceiling. Implementation target: passive card: preserve stronger Magic Immunity as the standard upgrade's rule using existing Magic Immunity family; fix speed/SV.
- Diamond Dragon: Keep the offensive alternate idea, reduce speed to `11`, and add the marked-quarry breath rule named in the implementation target. The HP/defense-for-attack trade is valid, but it still needs a faction thesis. Implementation target: attack/passive card: add Avenger-mark payoff to Dragonbreath Strike using the existing Avenger Mark damage-taken modifier family, with speed capped.

## Necropolis - Necromancy

Units should support attrition, death economy, fear, decay, and corpse control without making Necromancy outputs accidentally overpowered.

### Tier 1 - Skeleton Line

- Skeleton: No material change. It is the clean Necromancy conversion baseline. Implementation target: no new mechanic: preserve base Necromancy output; do not add combat utility to raised mass.
- Skeleton Warrior: No material change. It is a reasonable tougher Warrior Levy output. Implementation target: no new mechanic: preserve Warrior Levy durable raised output.
- Skeleton Archer: Fix by raising `SV` to about `90-100` while keeping Sharpshooter. Ranged Sharpshooter at `SV 38` is undervalued, especially if Grave Archers can raise it. Implementation target: attack card: keep ranged_attack plus Sharpshooter as Grave Archers output, but raise SV.

- Zombie: No material change. HP and Zombie Clutch make a clean reliability upgrade. Implementation target: active/passive card: preserve Zombie Clutch as the reliable tarpit upgrade using current Zombie Clutch family.
- Rot Zombie: Fix by retuning to `SV 180-190` and about `150g`, keeping Rotting Ray. `SV 353` is above Tier 2 for same-cost Zombie. Implementation target: active card: keep Rotting Ray as the decay debuff branch using current Rotting Ray family.

## Implementation Notes For A Later Pass

These recommendations should not be applied as scattered one-off edits. A production pass should add validators before changing generated data:

1. A generated-Core sidegrade validator that rejects alternate upgrades that are strict or near-strict combat-stat supersets unless an explicit exception documents the drawback.
2. A `squadValue` sanity validator that compares each custom row to tier band, gold cost, and sibling rows.
3. A Tier 4+ rule-density validator that flags mostly raw-stat rows where the balance bible expects engine, specialist, anchor, or capstone behavior.
4. An AI/role validator for obvious mismatches such as ranged rows tagged as melee.
5. A source-contract note for any row whose proposed identity depends on a custom hero skill, proving that the unit row uses visible card data rather than hidden runtime coupling.
