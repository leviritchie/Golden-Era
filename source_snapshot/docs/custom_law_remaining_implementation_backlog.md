## No-runtime implementation decision

| Readiness | Meaning |
|---|---|
| `native-exact-ready` | Static/native row can remain as the intended mechanic. |
| `source-prepared-runtime-blocked` | A matching source profile and predicate map exist, but packet gameplay remains disabled until runtime proof. |
| `temporary-compromise-playable-strict-placeholder-ready` | Playable source still has a known compromise, but the strict candidate strips it to a no-effect placeholder. |
| `source-prepared-surface-gap` | The profile exists, but one or more predicates are missing/rejected/unmapped in the surface matrix. |
| `strict-placeholder-not-ready` | A non-final target still has concrete bonuses in the strict candidate artifact. |
| `profile-missing` | No source-prepared profile matches the target; implementation would be guesswork. |
| `runtime-gate-open-ready-to-implement` | Packet proof gate is open; implementation may mutate gameplay through the prepared path. |
