## TAG: OVERVIEW

This project integrates **Heroes of Might & Magic: Olden Era** (Unity IL2CPP build) with data/assets from **HoMM 3 Complete** and **VCMI** to add custom factions, sprite replacements, UI overlays, and offline-play unlocks.

The primary mod is a **BepInEx 6 IL2CPP Harmony plugin** (`OfflineUnlockMod.dll`, C# netstandard2.1) located at:
```
Heroes of Might & Magic Olden Era Playtest/OfflineUnlockMod/
```

Installed loader version, verified from `BepInEx/LogOutput.log` and `BepInEx/core/*.dll` assembly metadata on May 4, 2026: **BepInEx 6.0.0-be.755**, built from commit `3fab71a1914132a1ce3a545caf3192da603f2258`. The log also reports .NET runtime **6.0.7**.

Supporting Python scripts and tooling live under `tools/`, `vcmi/`, and workspace root.

### Lang Args File Size Guard

- `HeroesOE_Data/StreamingAssets/Lang/args/unitsAbility.json` and `unitsBuff.json` are read by LocKit with `File.ReadAllText` during startup. If either file grows into gigabytes, the game logs `System.OutOfMemoryException` in `bxe.pbh()` / `il..cctor()` and startup stalls before eventually continuing.
- May 2026 root cause: `generate_homm3_stronghold_city.py` `propagate_base_args_to_upgrades()` matched already-upgraded custom SIDs like `h3_goblin_upg_*` as if they were base `h3_goblin_*` rows, allowing repeated runs to create nested SIDs such as `h3_goblin_upg_upg_*` and balloon `args/unitsAbility.json` / `args/unitsBuff.json`.
- Healthy post-patch sizes are small: `args/unitsAbility.json` about 35 KB and `args/unitsBuff.json` about 7 KB after Stronghold additions. If they are huge, restore them from a known-good copy (the `tools/reference/assetripper_olden_demo_unity/...` export was removed) and rerun `python generate_homm3_stronghold_city.py --lang-only`.
