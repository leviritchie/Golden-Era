# Golden Era v0.1.311

Hotfix over `v0.1.310`: the public installer Core overlay is rebuilt against the **installer-pinned June 4 Steam depot** Core.zip.

## Why

`v0.1.310` regenerated the Core overlay from the wrong clean baseline (`steamcmd-hommoe-poc`, SHA `f7879707…`) instead of the depot the thin installer validates (`b5b1dff2…`, manifest `5889655938380499086`). Depot detection could succeed, then `ValidateSourceCoreZip` failed closed on member hash mismatches.

`v0.1.309` was unaffected because it only scrubbed unfinished maps from an earlier correct payload and did not rebuild the overlay.

## Fix

- Regenerated `core_overlay` with `-CleanReleaseCore` = pinned depot Core.
- Packaging refresh scripts now fail closed unless clean Core SHA/size match the installer pin.
- Ships scrubbed plugin **0.1.311**.

Campaign / map content from `v0.1.310` is unchanged.

## Install

Same thin-installer flow: download one portrait EXE and run it. It downloads the payload parts from this Release.

Prefer **v0.1.311** over `v0.1.310`.

## Proof Boundary

Source/static: overlay `vanillaCore` matches installer pin; depot `ValidateSourceCoreZip` member hashes match. Installer end-to-end install remains user-unproven until exercised.
