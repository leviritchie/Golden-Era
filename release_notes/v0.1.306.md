# Golden Era v0.1.306

This release refreshes Golden Era from the current tested live-parity build and publishes two installer choices for hero portrait preference.

## Installer Choices

- `GoldenEraModInstaller-v0.1.306-upscaled-portraits.exe` installs with `homm3UseUpscaledHeroPortraits=true`.
- `GoldenEraModInstaller-v0.1.306-standard-portraits.exe` installs with `homm3UseUpscaledHeroPortraits=false`.
- Both installers are built from the same release payload and still install Golden Era into a separate game folder, leaving the Steam install vanilla.

## What's New

- Live-parity installer payload: campaign dialog portraits are injected into Unity `resources.assets` / `globalgamemanagers`, and the Factory `cityFactory` metadata pin is applied automatically.
- Curated campaign StreamingAssets ship with the installer (`Story_maps`, campaign videos, and related map content), not only the Core.zip overlay.
- Refreshed campaign/map content from the current tested Golden Era install, including recent map fixes.
- Continues the June 4 Olden Era Steam depot baseline; the installer still guides you through using that pinned build as the clean source.

## Validation

- Local release-candidate installers were built from this payload and smoke-tested before publishing.
- Diagnostics / live-probe / AI-driver surfaces remain stripped from the public DLL.
- GitHub Actions rebuilds both installer EXEs from the split LFS release-input parts (`release_inputs/golden_era_release_payload.zip.part*`) on this tag.
