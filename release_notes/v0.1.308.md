# Golden Era v0.1.308

This release refreshes Golden Era from the current tested live-parity build and publishes two thin installer EXEs for hero portrait preference.

`v0.1.306` built successfully but could not publish: GitHub rejects release assets at or above 2GB, and a single self-contained installer with the full payload is about 4GB. This tag ships **small installer EXEs** that download the shared payload parts from this GitHub Release automatically.

## Download And Install

1. Download one portrait variant EXE from this Release:
   - `GoldenEraModInstaller-v0.1.308-upscaled-portraits.exe`, or
   - `GoldenEraModInstaller-v0.1.308-standard-portraits.exe`
2. Double-click the EXE. The first run downloads the mod payload from this Release (about 4GB total across `.partNN` assets) and verifies SHA-256 before installing.
3. Complete the wizard. Golden Era still installs into a separate game folder and leaves Steam vanilla.

You do **not** need to download the payload `.partNN` files yourself unless you want an offline/air-gapped install: in that case, put every matching `golden_era_release_payload-v0.1.308.zip.partNN` file in the same folder as the EXE before running it.

## Installer Choices

- Upscaled portraits: `homm3UseUpscaledHeroPortraits=true`
- Standard portraits: `homm3UseUpscaledHeroPortraits=false`
- Both EXEs download the **same** payload parts; the EXE applies the portrait setting locally.

## What's New

- Live-parity installer payload: campaign dialog portraits are injected into Unity `resources.assets` / `globalgamemanagers`, and the Factory `cityFactory` metadata pin is applied automatically.
- Curated campaign StreamingAssets ship with the installer (`Story_maps`, campaign videos, and related map content), not only the Core.zip overlay.
- Refreshed campaign/map content from the current tested Golden Era install, including recent map fixes.
- Continues the June 4 Olden Era Steam depot baseline; the installer still guides you through using that pinned build as the clean source.
- Thin GitHub-hosted installers download the full payload from Release assets (no PowerShell join step).

## Validation

- Local release-candidate installers were built from this payload and smoke-tested before publishing.
- Diagnostics / live-probe / AI-driver surfaces remain stripped from the public DLL.
- GitHub Actions rebuilds the shared payload from split LFS release-input parts, publishes payload `.partNN` assets under the 2GB limit, and ships thin EXEs that download those parts.
