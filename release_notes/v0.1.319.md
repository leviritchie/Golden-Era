# Golden Era v0.1.319

The first release since August. It moves the mod to the current Olden Era Steam build and adds a large visual overhaul.

## Game build

- Ported to Olden Era Steam build **25672315** (depot 3105441, manifest `7750145598966689713`). Earlier releases targeted the June 4 build.
- If your Steam install is already on build 25672315, the installer can use it directly as the clean source. If Steam has moved on, the installer shows the depot command that downloads this build.
- The installer still copies the clean game into a separate Golden Era folder. Your Steam install is never modified.

## Distribution

- Installer payload parts are now ordinary GitHub Release assets (no more Git LFS bandwidth limits).
- The installer EXE is a thin downloader. It fetches the payload parts from this Release and checks their SHA-256 hashes before installing.

## 3D towns

- Every custom faction gets a full-3D town scene: Castle, Rampart, Tower, Inferno, Necropolis, Dungeon, Stronghold, Fortress, Conflux, Cove, Factory and Bulwark.
- The scenes are built from the HoMM3 town art, with skies, terrain, props and animated buildings.
- Town UI fixes, including the Conflux capitol showing at the third town-hall level, and faction HUD icons that no longer disappear.

## 3D creatures

- The custom factions and the HoMM3 neutrals use 3D animated creature models in place of 2D sprites.
- Their animations are retargeted from the original HoMM3 animations.
- Movement speed is normalized against similar Olden Era units (longer stride rather than slower movement).
- Battle sound effects for the 3D units.
- Vanilla-style visual effects for unit abilities and idle auras, matching Olden Era's own effect style.

## Adventure map

- 3D map meshes for faction towns and many HoMM3 adventure-map buildings, some of them animated.
- 3D artifact models.
- Campaign ocean and water-tile fixes for the current build.

## Gameplay and text

- The HoMM3 neutrals are wired into battle AI for the current build.
- Fixed missing text (LOC placeholders) on Stronghold Warcries, some mines and unit abilities; added translations for custom content in all 15 non-English languages (machine-translated, feedback welcome).
- Custom unit ability text now matches the effects that are actually configured, including Harpy and Fangarm.
- Fixed an end-of-combat softlock with synthetic units.
- Fixed a launch crash from a retired unit entry.
- Fixed campaign video delivery for the current build.

## Other changes

- New in-game bug report button. A report includes your description, the mod's log files with file paths and usernames scrubbed, a list of installed mod files, and a screenshot only if you tick the box. Reports go to a private folder only the author can see and are deleted after 90 days. GitHub Issues work too.

## Known issues

- The recruit panel can glitch in custom-faction towns. This is under investigation.
- Some flying creatures (for example griffins) still have rough flight animations.
- Castle's Elite Strategem abilities (Spread Out, Compress, Ambush) currently do nothing on this game build.

## Install

Download one portrait-variant EXE from this Release and run it. On first run it downloads the payload (about 10.5 GB in 6 parts) from this Release. For an offline install, put every `golden_era_release_payload-v0.1.319.zip.partNN` file next to the EXE before running it.
