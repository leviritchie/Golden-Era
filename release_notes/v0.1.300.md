# Golden Era v0.1.300

This is a targeted installer compatibility release for HoMM3 prerequisite detection.

## Fixed

- Fixed issue #6: clean Steam **Heroes of Might & Magic III - HD Edition** installs can use `HOMM3 2.0.exe` and `HOMM3Launcher.exe`. The installer now accepts those real Steam HD executable names instead of incorrectly rejecting the folder with "The selected HoMM3 folder does not look like HoMM3 Complete or HoMM3 HD."
- Kept the validator strict: GOG Complete and HD-mod style roots are still accepted, while unrelated folders are still rejected.

## Validation

- Built the installer project in Release configuration.
- Built a local `GoldenEraModInstaller-v0.1.300.exe` from the current release payload.
- Verified the patched validator against:
  - clean Steam HoMM3 HD root: accepted
  - local GOG Complete root: accepted
  - Olden Era game root: rejected
