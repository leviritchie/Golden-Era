# Golden Era v0.1.309

Cleanup release: unfinished test / comparison scenarios that accidentally shipped in `v0.1.308` are removed from the payload.

## Removed From Payload

- Layered-atlas / zone-atlas / approach-cell / single-layer / underground-slice / handedit / PoC map variants
- `vanilla_stock_*` comparison maps
- Procedural `proc_*` maps and `.procedural_scenarios` install records
- Broken leftover map files (`*broken*`, `water_example`)

Campaign `Story_maps` continuity missions (`*_raw_translation` and native `c_M*`) remain.

## Install

Same thin-installer flow as `v0.1.308`: download one portrait EXE and run it. It downloads the cleaned payload parts from this Release.

Also includes installer UX fixes from `main` after `v0.1.308` (download progress bar / live `DOWNLOAD:` log lines, and installer caches defaulting to `V:\Games\GoldenEra\InstallerCache` when V: exists).

## Note On v0.1.308

Prefer this tag over `v0.1.308`. The earlier tag’s payload included the unfinished test maps listed above.
