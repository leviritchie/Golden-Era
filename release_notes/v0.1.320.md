# Golden Era v0.1.320 (Preview)

> **If you installed v0.1.319, update to v0.1.320.** The v0.1.319 download was broken: it installed an older August build, so units showed up as 2D billboards and the in-game bug report button was missing. Download a v0.1.320 installer, run it, choose **Update an existing Golden Era copy**, and select your existing Golden Era folder.

> **This is a preview build, not a finished release.** It still has a lot of issues. Notably, many units have very unfinished animations.

v0.1.320 is the build v0.1.319 was meant to be: the October payload with the 3D units, 3D towns and the bug report button. It also includes the fixes listed below.

## What changed since v0.1.319

- Fixed the release download. v0.1.319's payload was replaced by the August payload shortly after it was published. v0.1.320 ships the current payload, and the release process now checks after publishing that the files on the Release are the ones that were built.
- Quick play faction icons: fix included, not yet confirmed in game.
- The payload is now about 11.8 GB in 7 parts (v0.1.319 listed 10.5 GB in 6).

## Game build

- Ported to Olden Era Steam build **25672315** (depot 3105441, manifest `7750145598966689713`). Earlier releases targeted the June 4 build.
- If your Steam install is already on build 25672315, the installer can use it directly as the clean source. If Steam has moved on, the installer shows the depot command that downloads this build.
- The installer still copies the clean game into a separate Golden Era folder. Your Steam install is never modified.

## Distribution

- Installer payload parts are ordinary GitHub Release assets (no Git LFS bandwidth limits).
- The installer EXE is a thin downloader. It fetches the payload parts from this Release and checks their SHA-256 hashes before installing.

## 3D towns

- Every custom faction gets a full-3D town scene: Castle, Rampart, Tower, Inferno, Necropolis, Dungeon, Stronghold, Fortress, Conflux, Cove, Factory and Bulwark.
- The scenes are built from the HoMM3 town art, with skies, terrain, props and animated buildings.
- Town UI fixes, including the Conflux capitol showing at the third town-hall level, and faction HUD icons that no longer disappear.

## 3D creatures

- The custom factions and the HoMM3 neutrals use 3D animated creature models in place of 2D sprites.
- Their animations are retargeted from the original HoMM3 animations.
- Movement speed is normalized against similar Olden Era units (longer stride rather than slower movement).
- Battle sound effects for the 3D units.
- Vanilla-style visual effects for unit abilities and idle auras, matching Olden Era's own effect style.

## Adventure map

- 3D map meshes for faction towns and many HoMM3 adventure-map buildings, some of them animated.
- 3D artifact models.
- Campaign ocean and water-tile fixes for the current build.

## Gameplay and text

- The HoMM3 neutrals are wired into battle AI for the current build.
- Fixed missing text (LOC placeholders) on Stronghold Warcries, some mines and unit abilities; added translations for custom content in all 15 non-English languages (machine-translated, feedback welcome).
- Custom unit ability text now matches the effects that are actually configured, including Harpy and Fangarm.
- Fixed an end-of-combat softlock with synthetic units.
- Fixed a launch crash from a retired unit entry.
- Fixed campaign video delivery for the current build.

## Other changes

- In-game bug report button. A report includes your description, the mod's log files with file paths and usernames scrubbed, a list of installed mod files, and a screenshot only if you tick the box. Reports go to a private folder only the author can see and are deleted after 90 days. GitHub Issues work too.

## Known issues

- Many units still have very unfinished animations.
- Quick play faction icons: a fix is included but not yet confirmed in game. Please report it if they still look wrong.
- The recruit panel can glitch in custom-faction towns. This is under investigation.
- Some flying creatures (for example griffins) still have rough flight animations.
- Castle's Elite Strategem abilities (Spread Out, Compress, Ambush) currently do nothing on this game build.

## Install

Download one portrait-variant EXE from this Release and run it. On first run it downloads the payload (about 11.8 GB in 7 parts) from this Release. For an offline install, put every `golden_era_release_payload-v0.1.320.zip.partNN` file next to the EXE before running it. The drive that holds the modded copy needs about 22 GB free (12.9 GB unpacked mod plus 7.2 GB of game files, plus a margin), and the download needs another 11.8 GB wherever the installer is saved.

To update an existing Golden Era copy (including one installed from v0.1.319), run the v0.1.320 installer and choose **Update an existing Golden Era copy**.
